## 💫 Sobre Mí

Soy un profesional del software especializado en **Automatización de QA** y **Desarrollo Full-Stack Moderno**. Mi enfoque actual es revolucionar el ciclo de vida del testing mediante la ingeniería de **Agentes de IA Autónomos** capaces de analizar requisitos, planificar y ejecutar pruebas de forma automática.

- 🚀 **Actualmente construyendo:** Ecosistemas de QA Autónomos utilizando AI-DLC, Kiro IDE y el protocolo MCP (Model Context Protocol) integrado con Playwright.
- 💻 **Actualmente trabajando en:** Desarrollo web Full-Stack utilizando el ecosistema moderno de React (Next.js, Tailwind, Prisma) e impulsando la adopción de automatización de QA con IA.
- 🤖 **Perfil único:** Tengo una gran pasión por la robótica educativa, desarrollando y guiando equipos con microcontroladores (Arduino/C++) y plataformas LEGO.
- ⚡ **Dato curioso:** En mi tiempo libre, toco el violín 🎻, leo libros de ciencia ficción 📚 y construyo robots 🦾.
